# 店舗訪問（shop-visit）

ひいらぎHDグループの店舗訪問を記録するPWA。店舗を選び、訪問日時・観察（◎○△）・対話・課題・写真を
チップ選択式で残す。同じ店舗に何度でも記録できる。

## 初回セットアップ（iPhone）

1. Safariでアプリを開く: https://fugangliang.github.io/shop-visit/
2. 共有ボタン → **ホーム画面に追加**（以後は必ずホーム画面のアイコンから起動する。Safariタブ版とはデータ保存領域が別のため）
3. 初回起動時に店舗マスター（公式サイトの店舗一覧）が自動取得される（オンライン必須・以後は24時間ごとに自動更新）

## 使い方

- **訪問タブ**: 店舗を選ぶ（検索／会社・ブランド・都道府県の絞り込み／最近・よく行く）→ A訪問基本（日時・時間帯・形態・同行者・目的・実食）→
  B観察（各軸を◎○△＋補足チップ）→ C対話（相手・テーマ・温度感・要旨）→ D課題（判定・重要度・宛先・期限）→ E写真 → 保存。
  必須は店舗と日時のみ。開いたセクションだけ入力すればよい。
- **カバレッジ**: 訪問タブ上部。会社×ブランド別の訪問済／未訪問数。行をタップすると絞り込まれる。
- **記録タブ**: 保存した訪問の一覧（会社・判定で絞り込み）・削除
- **設定タブ**: 店舗マスター更新／手入力店舗の管理／エクスポート（全件・前回以降・テキストコピー）／取込／全削除

## 訪問後

設定タブ →「写真込みJSONを書き出し」→ AirDropまたはファイルでMacへ → Claudeに「店舗訪問記録を取り込んで所見を整理して」と依頼。

## 注意

- 記録はこのiPhoneの中にだけ保存される（外部送信なし）。機種変更前・全削除前に必ずエクスポート。
- 発言要旨に氏名は書かない（役職まで）。
